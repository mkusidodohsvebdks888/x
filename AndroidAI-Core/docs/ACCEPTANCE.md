## v0.3 外卖辅助验收

- [ ] 真机手动启用 Android AI Core 无障碍服务，状态可正确检测。
- [ ] 未开启会话时 DeepSeek 不会获得外卖交互工具。
- [ ] 已授权目标 APP 后，工具仅能读取该 APP 前台窗口。
- [ ] 搜索词输入、匹配文字点击、滚动均产生可核查结果。
- [ ] 密码字段及输入框原文不在扫描结果中出现。
- [ ] 订单提交或支付界面触发停止，不执行最终提交或支付。
- [ ] 会话 20 分钟超时、用户停止、应用重启时立即失效。
- [ ] Termux 原有功能、AI 对话、日志、设置不回归。

## v0.4 Codex 式循环验收

- [ ] 仅提交一条任务即可自动进行多次模型请求/工具执行/结果反馈。
- [ ] AI 对话界面显示轮数、工具次数、步骤状态，并在工具调用时更新。
- [ ] 任务成功时立即退出循环，不继续消耗 API。
- [ ] 遇到网络错误、HTTP 429/5xx 最多重试两次；HTTP 401/403 不重试。
- [ ] 相同工具和参数连续 3 次返回相同结果时中止，提示没有进展。
- [ ] 24 轮/64 个工具/10 分钟上限触发时明确标记尚未完成。
- [ ] 用户点停止后不再发起新的模型调用或新的工具操作；已启动的外部命令可能持续。
- [ ] 任务可读日志不包含 API Key、搜索内容或无障碍页面原文。
- [ ] 不改变现有外卖结算/付款的人工确认边界。
- [ ] 红米 13C 真机测试前后台、运行中停止、权限失效及网络波动。
