### 初始意图分类

| 意图代码 | 分类 | 示例 |
|---|---|---|
| PRICE | 询价 | 多少钱、最低多少 |
| PRODUCT_DETAIL | 商品细节 | 规格、型号、成色 |
| STOCK | 库存 | 还有吗、有货吗 |
| LOGISTICS | 物流 | 什么时候发货 |
| AFTER_SALES | 售后 | 怎么使用、出现问题 |
| TRANSACTION | 交易状态文案 | 订单、付款状态 |
| OTHER | 其他 | 可读但未命中规则 |
| UNKNOWN | 无法判断 | 正文缺失或规则冲突 |

意图分类仅用于本地记录，不触发回复、订单或交易动作。

## 9. V1.0 明确不包含

- 自动点击、输入、复制、粘贴、滚动、手势或页面导航。
- 自动发送、回复、撤回消息。
- 自动下单、付款、确认收货、发货、退款或评价。
- 闲鱼私有 HTTP / WebSocket 接口、协议逆向、Cookie / Token 读取。
- 截屏、录屏、MediaProjection、OCR。
- 云端 API、AI API、DeepSeek 调用、云同步。
- 后台自动打开聊天或读取未由用户主动打开的页面。
