# V1.0 测试与验收计划

> 当前状态：测试计划已建立；实现、编译、安装和真机验收均未开始。

## 1. 测试原则

- 使用本人控制的 Android 设备、闲鱼账号和测试会话。
- 页面切换、聊天打开和滚动由用户手动执行。
- 测试只验证读取与本地保存，不测试发送、付款或发货。
- 使用脱敏 fixture 做解析器单元测试；真机数据不得提交到 Git。
- 每项记录 PASS / FAIL / NOT RUN，附设备、系统版本、APP 版本和脱敏证据。

## 6. 量化验收目标

以至少 50 组本人控制的测试样本建立人工标注基准：

- 可访问可见文本提取准确率目标：≥95%。
- 测试集跨会话错误绑定：0。
- 不确定商品错误自动确认：0。
- 非闲鱼页面被解析：0。
- 自动 UI 写操作：0。
- 未授权或无法读取时伪造成功：0。
- 本地已保存数据重启恢复：100%。

如果页面本身没有暴露某个字段，该字段不计为解析器失败，但必须被标记为不可用 / unknown，不能从准确率中隐藏错误绑定。

## 7. 最终验收

只有 RO 静态检查通过、页面读取测试完成、身份和商品绑定测试通过、数据库恢复测试通过，才能宣布 V1.0 验收完成。

未运行的项目必须保持 NOT RUN。源码存在不代表编译成功；编译成功不代表安装成功；安装成功不代表真机识别准确。
