# 开发路线图

## 当前阶段：V1.0 规划与文档初始化

已确定：
- Android 原生 APP。
- AccessibilityService 只读读取闲鱼当前窗口。
- 本地 Room / SQLite。
- 买家、会话、商品卡片和消息意图识别。
- 不自动操作闲鱼，不接 AI / 网络 API，不做交易。

尚未完成：
- Kotlin / Gradle 工程。
- AccessibilityService 实现。
- 页面解析器。
- Room 数据库。
- 本地识别界面。
- 编译、安装和真机验收。

## P0 — Android 工程骨架

- 建立 Gradle / Kotlin Android 工程。
- 配置 Manifest 和最小权限。
- 建立只读 AccessibilityService 壳层。
- 增加静态只读边界检查。
- 验收：可编译；源码无 UI 写操作和网络权限。

## P1 — 页面 Snapshot

- 只读取闲鱼当前窗口节点。
- 提取必要文本、描述、控件 ID、类型和 bounds。
- 合并重复页面事件。
- 验收：与人工标注的可见节点内容对照一致。

## P2 — 页面与会话解析

- 识别聊天列表与聊天详情。
- 提取买家显示名称、消息正文和方向线索。
- 对缺失平台身份字段保持 unknown。
- 验收：同昵称买家不会被错误合并。

## P3 — 商品卡片识别

- 提取可见商品标题、价格及明确暴露的商品 ID。
- 建立本地商品库。
- 标题 / 价格只用于候选匹配。
- 验收：歧义商品必须待确认。

## P4 — 本地消息意图分类

- 关键词与正则规则。
- 多意图与未知分类。
- 不接远程模型。
- 验收：规则输出可解释，未知消息不强行分类。

## P5 — Room 数据库与识别 UI

- 买家、会话、商品、消息、绑定、证据表。
- 本地列表、筛选和人工确认。
- 本地数据清除。
- 验收：重启恢复和去重测试通过。

## P6 — 真机验收

- 受控账号和多会话测试。
- 50 组以上人工标注样本。
- 完成 docs/TEST_PLAN.md。
- 只报告真实执行过的结果。

## 未来版本

任何自动回复、云端 AI、协议层接入、订单处理或发货能力均不属于 V1.0。未来若讨论，必须独立评估并获得明确确认，不得悄悄加入当前版本。
