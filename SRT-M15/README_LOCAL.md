# SRT-M15：本地输入框 + 受控自主学习实验版

这是从随机权重训练的小型研究模型，而不是通用聊天大模型。本版本在原本的本地问答窗口上新增 **自动学习开关、错误样本队列、候选参数训练、独立检验、自动保存与手动回滚**。

## Windows 启动

1. 解压 `SRT_M15_Auto_Learning_Local.zip`，进入 `SRT_M15_Starter` 文件夹。
2. 安装 Python 3.10 或更高版本。建议在虚拟环境中执行 `python -m pip install -r requirements.txt`。
3. 双击 `start_windows.bat` 或执行 `python start_local.py`。
4. 浏览器打开 `http://127.0.0.1:8765/`。服务仅绑定本机地址，不依赖云端 API。

macOS / Linux：执行 `python3 -m pip install -r requirements.txt`，然后执行 `python3 start_local.py`。

## 输入和运行方式

- 输入 `1+9=多少` 等两个 0～9 整数的加法：由神经网络预测，同时显示确定性验证器提供的真实答案。
- 输入 `你好`：由字符语言模型尝试续写。它仍没有可靠的开放域问答能力。
- 开启网页上方「**启用自动学习**」：默认关闭，只有开启后才积累已验证的数学错误。
- 当收集到 **3 个不同、在允许训练范围内且预测错误的加法样本**时，会在后台训练一次候选快速参数。页面显示队列数量和训练状态。
- 「**手动训练队列**」可对当前已有的合格样本提前尝试训练，但不能使用未验证的内容。
- 「**撤销上次更新**」恢复之前的候选版本；没有历史版本时恢复原始模型。

## 自主学习的边界和保护

- 此版本的自动学习**仅针对单数字加法**；中文聊天不会触发语言权重自学习，更不会把模型自己生成的回答当真值。
- 原始模型的 `train_pairs` 中有一部分预留作检验数据，原始 `test_pairs` **完全排除在训练与更新筛选之外**。
- 候选模型与当前正在回答问题的模型隔离；先训练候选权重，只有实际使用的硬路由推理在错误样本上提高、检验集不退化、基础检验全部通过时才接受更新。其他情况不覆盖现有权重。
- 受控更新目前只训练分支中的 `fast_down` / `fast_up` 可塑参数，不训练共享 Transformer 主干。
- 为了避免循环耗尽 CPU，默认最多记录 12 次自动训练尝试，训练间隔至少 10 秒。达到限制后会停止自动启动。
- 初始实验集仅有 100 种个位数加法，**不能据此证明通用自主学习已经实现**。检验集用于版本筛选，不能作为最终泛化成绩；真实研究还需要额外从未参与筛选的独立评估。

## 新产生的本地文件

- `checkpoints/srt_m15_toy.pt`：**原始数学权重**，始终不会被覆盖。
- `checkpoints/srt_m15_toy_adapted.pt`：检验通过后**自动保存的适配权重**，下次启动优先加载。
- `checkpoints/srt_m15_toy_previous.pt`：更新前的适配版本（如果存在），供回滚使用。
- `checkpoints/autolearn_state.json`：自主学习开关、任务队列、训练状态和结果，不保存用户自由聊天文本。
- `checkpoints/srt_m15_lm.pt`：原先训练的中文字符模型，不会被自动学习修改。


## 将来扩展

目前缺少可靠开放问答数据和校验机制，因此不宜为语言模型直接开放无监督自动微调。后续可以独立加入人工标注训练队列、可追溯数据版本和专用验证集，循序扩展可学习任务。

## 联网自主学习

新版浏览器界面增加「联网自主学习」区域，默认为关闭。需手动授权、设定主题和资源上限后，才会连接固定的中/英文维基百科 API。详情请看 `README_INTERNET_LEARNING.md`。资料存在 `web_memory/`，**不是直接写入神经网络权重**。


### 中文训练实验新增入口

进入页面新增「中文问答 · 受控持续学习」区域，可导入演示草稿、逐条批准，或从人工审核的百科资料中生成草稿并核对。仅在用户主动点击训练后才会使用经审核问答更新新的 UTF-8 字节语言模型。详细见 `README_LANGUAGE_LEARNING.md`。

**新增中英双语学习：** 可导入24对中文/英文问答草稿，逐条批准后进行中英均衡训练，并分别检查两种语言的训练和独立检验损失。详见 `README_BILINGUAL_LEARNING.md`。
