# SRT-M15｜10,000 条双语样本与多批次训练（v3）

## 目标与真实状态

本版提供一个**可复现的生成器** `generate_bilingual_10k.py`，自动生产 **10,000 条 JSONL 中英文问答**（**5,000 条中文 + 5,000 条英文；5,000 个成对话题**）。保留原 v2 的全部 1,000 条，在其基础上新增 **9,000 条**原创合成样本。**生成的 10k 数据文件是 GitHub Actions 运行时产物，不必把一个多兆字节的大文件直接写入 Git 历史**。

数据为**AI 编写和程序化模板组合的教学合成数据**；并非从 GPT、Claude 等模型抽取的专有训练语料，没有由母语者逐条复核。所有新条目 `verified=false`、`synthetic=true`，仅在显式 `--allow-demo-data` 时用于实验。不要将数量宣传为“已经学会 10,000 种语言能力”，也不要自动更改已审核标志。

## 生成方式

进入 `SRT-M15/`：

```bash
python generate_bilingual_10k.py \
  --output examples/bilingual_synthetic_v3_10000.jsonl \
  --manifest examples/bilingual_synthetic_v3_manifest.json
```

该操作不使用网络 API、密钥或网页抓取；固定算法与固定种子文件使输出可复现。生成后立即进行 JSON 读取、语种数量、重复提问、话题分组交叉检查，并输出 SHA-256 摘要。

### 覆盖内容

原有 1,000 条（包括问候、工作、旅行、语法、计算机等）保持不变。新增 4,500 个中英成对话题：

| 新增类型 | 成对话题 | 中/英样本 |
| --- | ---: | ---: |
| 加法 | 600 | 1,200 |
| 减法 | 600 | 1,200 |
| 乘法 | 600 | 1,200 |
| 数字比较 | 300 | 600 |
| 奇偶判断 | 300 | 600 |
| 数字排序 | 300 | 600 |
| 日常词汇 | 900 | 1,800 |
| 生活工作情境：解释、建议、求助 | 900 | 1,800 |
| **新增合计** | **4,500** | **9,000** |

**重要局限：** 绝大多数新增算术题属于确定性程序生成；词汇、场景含重复模板和表达方式，不能代替自然语料的大范围语言现象。适合作为验证训练器、跨语言平衡和断点续训的测试数据，不足以让 25k 参数级实验模型掌握普通中文和英文。

## 数据隔离与质量

`topic_id` 对齐中英文同一话题；`family_id` 标记同模板家族；新合成数据按整个**模板家族**设定固定 `train` 或 `dev`，避免近似改写跨数据集。旧 1,000 条按原先的话题分组策略划分。实际 train/dev 数量由生成器 manifest 记录。

模板家族级隔离比按随机行划分严格，但算术样本存在跨家族的模式相似性。因此留出指标仍仅属于此合成集合，**不是独立的通用语义能力验证**。

## GitHub Actions 多批次训练

进入 Actions 里的 `SRT-M15 staged bilingual training`：

- `training_dataset`：`synthetic_10000`（默认）；
- `stages`：`10`（默认，十批分别记录、分别保存）；
- `steps_per_stage`：`160`（每批 160 个优化器更新）；
- `resume_run_id`：第一次**留空**，续训使用同一数据及超参数的**上次成功运行编号**。

此配置使用 `context=256`，`batch_size=16`，`sampling=cycle`。**Cycle 的实际含义**：中英各保留一个确定性打乱顺序，无放回取出模型的训练窗口；遍历所有训练窗口后才进入下一个周期。检查点保存采样顺序和游标，因此下次能继续覆盖尚未用到的窗口，而不是每次重新随机挑选最常见样本。

10 批×160 步×16 个训练窗口 = **每次最多 25,600 个训练窗口参与优化**（注意：一个问答可能产生一个以上训练窗口；训练集保留部分数据作为验证，不存在“每条样本都要用 25,600 次”的含义）。报告 `cumulative_unique_window_coverage` 会显示每种语言实际覆盖的唯一训练窗口数。即使覆盖达到 100%，也并不说明已经学会语言。

CPU 工作流设置 90 分钟上限；达到 GitHub Actions/账户计算配额等限制可能提前停止。权重保存在 `latest.pt`（续训）和 `best.pt`（符合有限评测提升要求时晋升），历史在 `history.json`，数据与清单作为单独 artifact 上传，保留 14 天。**训练检查点不自动推送到公开 Git 仓库**。

本地示例：

```bash
cd SRT-M15
python generate_bilingual_10k.py
python train_bilingual_stages.py \
  --data examples/bilingual_synthetic_v3_10000.jsonl \
  --allow-demo-data --sampling cycle --context 256 \
  --batch-size 16 --stages 10 --steps-per-stage 160 \
  --output checkpoints/bilingual_stages
```

### 兼容限制

当前从零训练的 v3 新词表和新上下文不同于 v2（1,000 条）的 checkpoint，**不能通过 `--resume` 直接加载旧参数**。恢复需要数据 SHA、模型结构、批次大小、批次步数和采样模式完全一致。跨数据集迁移学习将作为独立且需要新验证的开发任务。

## 训练验收的严谨解释

GitHub 工作流执行成功，只代表数据生成、梯度更新、指标记录与模型文件保存成功；回答准确率、中文完整句子的可理解程度、英文语法、多轮对话和未见事实问答，仍需真正独立评估。目前仍处早期研究阶段，不应声称达到正常双语聊天水平。
