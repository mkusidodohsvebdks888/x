# SRT-M15 双语合成训练语料 v2 · 数据说明

## 数据状态

- 数据文件：`examples/bilingual_synthetic_v2_1000.jsonl`
- 内容：**1,000 条中英文问答**；**500 条中文、500 条英文**；共 **500 个成对话题**。
- 来源：助手为本项目编写与程序化扩展的**原创合成训练候选数据**，并非真实世界采集的大规模语料，也不是从 GPT、Claude、DeepSeek 等产品提取的私有训练集。
- 审核：**未经逐条人工审核**（`verified:false`、`review_status:"unreviewed"`）。默认不能作为已经事实核查的数据；实验必须加 `--allow-demo-data`。
- 来源标记：保留原 v1 的 260 条记录及其原来源字段；新增 740 条记录标记为 `assistant-authored-synthetic-2026-10-23-v2`。
- 与 v1 的关系：文件前 260 条保留不变，在后面追加 740 条；**原有 v1 数据文件没有被覆盖**。

## 内容覆盖

v1 的 13 类基础日常主题保持不变。新增的 370 组话题（740 条）如下：

| 新增分类 | 双语话题组 | 中文样本 | 英文样本 |
|---|---:|---:|---:|
| 基础算术（加减乘） | 90 | 90 | 90 |
| 高频词汇（中英互译） | 60 | 60 | 60 |
| 真实生活情境（说明、求助） | 60 | 60 | 60 |
| 英语语法（解释、例句、检查） | 60 | 60 | 60 |
| 计算机基础（概念、用途） | 50 | 50 | 50 |
| 决策与学习计划（开始、避免） | 50 | 50 | 50 |
| **新增合计** | **370** | **370** | **370** |

**限制：** 算术样本由确定性公式生成，文本学习样本部分采用人工设计的问题和句式模板；语法/计算机说明存在语义重复。1,000 条数据不是 1,000 种独立能力，更不是通用中文/英文语料。相同话题中英文的表达经过改写，不必保证字面对齐，但必须检查语义。

## 分割策略

每个话题保留唯一 `topic_id`，`bilingual_data.split_records` 根据话题分割，避免中文问题进训练、同话题英文问题进入留出评估。

以默认训练/验证比例 80%/20%：

| 数据 | 训练 | 留出验证 |
|---|---:|---:|
| 中文 | 400 | 100 |
| 英文 | 400 | 100 |
| 总量 | 800 | 200 |

此验证只是当前合成主题的 Token 预测指标。要测开放领域泛化，必须再创建**独立来源/表达方式**的外部测试集，而不是反复优化同一留出集。

## GitHub Actions 使用方式

进入 `Actions → SRT-M15 staged bilingual training → Run workflow`，`training_dataset` 选 `synthetic_1000`（默认），`stages=2`，`steps_per_stage=20`。首次训练 `resume_run_id` 留空，完成后从该次 Actions 的 artifact 下载最新权重。下次续训时填写**同一数据集、同一训练参数**的上一次成功运行编号。

**训练配置说明：** 当前 workflow 对 v2 使用字符上下文长度 `208`，以覆盖本数据包最长约 200 字符的完整问答；v1 和 toy 数据仍保持 `32`。较早使用 v2、`context=32` 的 checkpoint 与新 workflow **不兼容**，不能作为新配置的 `resume_run_id`。不同数据文件的 checkpoint 也不能直接做完全恢复：数据哈希和词表均可能变化。

手动从零训练：

```bash
cd SRT-M15
python train_bilingual_stages.py \
  --data examples/bilingual_synthetic_v2_1000.jsonl \
  --allow-demo-data --context 208 \
  --stages 2 --steps-per-stage 20
```

## 对「训练成功」的解释

- GitHub Action 成功：真实完成了一次有上限的 CPU 梯度训练，并已保存可续训模型。
- 训练/验证损失降低：模型在有限语料上的字符概率预测出现改善。
- 「中文、英文普遍正常使用」：**尚未证明**。当前原生实验模型参数极少，数据覆盖有限。应扩大受许可语料、模型容量，采用适合长文本的 Tokenizer；结合盲评与外部测试集再判断。

这是实验性数据集，不能把自动生成数据数量视为模型已取得同等规模的可靠知识。
