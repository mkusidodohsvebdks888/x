SRT-M15 本地自主练习（仅两个 0～9 整数加法）

Windows:
1. 解压本 ZIP，进入 SRT_M15_Starter 文件夹。
2. 安装 Python 3.10+。
3. 在文件夹中打开命令行：
   py -3 -m venv .venv
   .venv\Scripts\activate
   python -m pip install -r requirements.txt
4. 双击 start_windows.bat，浏览器打开 http://127.0.0.1:8765/ 。
5. 在“自主练习”中设置间隔、每轮题数、最大训练次数、最长时间和最多题数，点击“开始自主练习”。
6. 可随时点击“暂停”；查看题数、错误、待学习样本和训练结果。

macOS/Linux 见 README_SELF_PRACTICE.md。

- 只抽样允许训练的加法题，不把检验题/测试题作为训练样本。
- 错误由确定性加法验证器确认；候选必须通过效果检查才保存。
- 原始模型和中文模型不覆盖。可回滚已保存的适配参数。
- 默认不自动启动练习，重启后只恢复数据及权重。
- 不需要 Google Colab，不调用外部模型 API。
- 研究原型：不能自主学习中文、编程或互联网知识。

中文问答受控训练：在网页下方「中文问答」区域先导入20条演示问答草稿、逐条批准，再点「训练候选语言模型」。训练会验证损失，可能拒绝更新。详细见 README_LANGUAGE_LEARNING.md。
