# SRT-M15：中文输入、审核问答与受控语言学习（本地实验版）

这是在 SRT-M15 **联网自主学习 + 个位数加法自主练习**版本上增加的实验功能。新模块为 `srt_m15/supervised_language.py`；原来的加法神经网络、字符语言模型、网络记忆数据库均保留。

> **重要：该版本尚不具备可靠通用问答能力。**
> UTF-8 字节词表意味着**任意 Unicode 输入都可以被编码**，并不代表模型理解这些文字。训练中验证损失下降也不代表掌握了通用中文、数学或编程。

## 本地启动

要求 Python 3.10+；推荐使用干净的虚拟环境。Windows 解压后双击 `start_windows.bat`，或者在 `SRT_M15_Starter` 目录运行：

```bash
python -m pip install -r requirements.txt
python start_local.py
```

进入 `http://127.0.0.1:8765/`。首次使用不需要 Colab，也不需要外部大模型 API。项目会保留之前的聊天输入框。

## 训练文字模型：三种来源

1. **演示问答**：点击「导入20条演示问答草稿」。这些是项目自身行为的简短示范，**全部是待审核状态，不会自动进入训练**。逐条查看并点击「批准训练样本」。
2. **手动问答**：在问题、答案框内编写经你核实的简短文本，点击「保存待审核问答」，随后逐条批准。单条编码后长度不超过160字节（中文通常占3字节）。可通过「修改问答」改写后再次审核，也能撤销批准。
3. **联网资料**：先在上方「联网自主学习」面板**明确授权联网**并收集摘要，再对资料人工审核。在已审核资料卡片中点「生成问答草稿」，修改并核对答案、保存草稿、再单独批准。**已审核网页 ≠ 已验证训练标签**。

只有被逐条批准的问答才会纳入训练。联网权限和训练操作是相互独立的。**没有任何“网页一出现就直接训练权重”的路径。**

训练池与独立验证池通过不可变分组规则划分：同一 Wikipedia 资料编号形成的多个问答必须在同一分区；手工问答按规范化问题分组。分区稳定约为80%/20%，不保证每次新建数据刚好是该比例。至少需要**4条训练池样本和2条独立验证样本**；20条演示题全部批准后一般为16条训练、4条验证。

点击「训练候选语言模型」，默认30步、最长100秒，当前允许最多100步和240秒。训练在本机受限制的后台线程执行；「暂停训练」可中止后续步骤。重启时不会自动继续训练。

只有候选的**训练集目标预测损失下降至少0.005、独立验证集损失不高于训练前、权重有限且候选检查点可以重新加载**时，才激活新的语言权重。否则丢弃候选、保留旧版本。**单靠少量验证题的损失不会证明知识正确或泛化可靠。**

## 权重保护、升级与回滚

- 原来的 `checkpoints/srt_m15_lm.pt` **完全保留**。
- 原来的 `checkpoints/srt_m15_toy.pt` **完全保留**，加法自练算法不变。
- 新模型使用 **256词表的 UTF-8 字节级 tokenizer**，独立保存到 `checkpoints/srt_m15_byte_qa.pt`。初次训练从随机权重开始；后续训练更新可塑性模块和输出头参数。
- 同意更新后，已加载的聊天模型会重新加载新权重，而不是直接复用旧的内存对象。
- 上一版字节模型保存到 `checkpoints/srt_m15_byte_qa_previous.pt`（只有一层回滚）。如果是首次接受训练，回滚将移除新的字节版，转回原有字符模型。**模型一旦已从错误文本学到内容，撤销审核不等于自动“遗忘”；必要时请回滚并审查数据。**
- SQLite 中的问答及审核信息位于 `language_learning/reviewed_qa.sqlite3`；训练状态在 `language_learning/training_state.json`。训练线程在进程重启后保持停止状态。

备份建议：保存整个 `checkpoints/`、`language_learning/` 和 `web_memory/` 目录。

## 为什么不能自动相信百科摘要？

摘要可能过时、有歧义、存在错误，且文章标题不能直接证明摘要中包含准确答案。当前做法是展示来源，提供草稿，人工核对问题与短答案，训练后看留出的验证损失。**模型在聊天中自己生成的答案不会自动变成训练标签。**

若将 Wikipedia 摘要或衍生文本对外分发，需保留来源与适用许可信息，查看各文章的许可证及署名要求；此项目不自动为你取得再授权许可。

## 性能与局限

小模型从随机参数学习语言需要足够多的高质量监督数据，20条演示问答只能验证训练管线，不足以形成稳定的聊天能力。字节级编码解决“输入中存在未知字符”的程序错误，但可能输出无意义文本或不完整的 UTF-8 字节，需要更多数据和更好的分词策略。联网记忆检索依然是显示带来源资料的独立路径，不等同于语言模型学会了资料内容。
