# SRT-M15：联网自主学习（带来源的本地知识记忆）

本版本在 **SRT-M15 Autonomous Practice Local** 上增加了 **联网知识获取、来源引用、审核、持久化、本地检索**。原来的个位数加法自主练习和快速参数更新机制保持独立。

> **重要能力边界**：这里的“联网自主学习”是 **知识库/检索记忆的持续积累**，**不是**从互联网资料自动训练 Transformer 权重。网页可能有错误、被修改或过时；没有独立验证的文本不会被当作正确训练标签。
>
> 当前 SRT-M15 的神经网络权重自动更新只在已有的 **0～9 个位数加法、确定性验证**实验中发生。联网模块不改变任何 `.pt` 文件、训练集、检验集或测试集。

## 本地启动

在解压出的 `SRT_M15_Starter/` 目录中运行：

```bash
python -m pip install -r requirements.txt
python start_local.py
```

Windows 可双击 `start_windows.bat`。打开浏览器访问 `http://127.0.0.1:8765/`。由于服务仅监听本机回环地址，其他设备默认不能直接访问。

## 操作步骤

1. 进入页面的 **联网自主学习** 区域。
2. 勾选 **「明确允许联网」**（每次重启都需要重新授权）。
3. 在主题框中输入 **1～10 个**知识主题，如 `神经网络, 深度学习, Transformer`。这些查询会发送到 Wikimedia 服务器。
4. 保持默认限额（每次最多12次网络请求、180秒、24条新资料、最短间隔12秒）或在页面调整。
5. 点击 **「🌐 开始联网学习」**。软件会自动从百科中获取相关主题，保存摘要、标题、来源网址和获取时间，并可以有限度地从文章标题拓展后续学习主题。
6. 点击 **「⏸ 暂停联网」**可以停止后续网络请求。运行时间、请求数、资料数达到限额也会自动停止。
7. 在最近资料卡片中选择 **「标记已审核」**或者 **「拒绝此资料」**。人工标记不是绝对正确性证明。
8. 在聊天输入框中输入 `什么是神经网络？`，系统在**已启用联网授权且有匹配资料**时优先显示本地知识库摘录和明确的来源网址。也可以输入 `联网搜索：神经网络` 主动获取最新摘要。
9. 可以用 **「导出已审核资料」**下载 `.jsonl` 文件，供将来单独构建有监督训练集使用。**导出本身不会训练神经网络**。

## 保存位置与重启

`web_memory/sources.sqlite3`：本地 SQLite 知识库，保存资料、来源、人工审核状态。

`web_memory/study_state.json`：联网检索计数、最近结果、上次设置。

重新启动软件后资料和审核结果仍在，**联网授权和后台任务默认关闭**，不会私自继续访问互联网。

**原来的数学和中文权重不会受到影响**：

- `checkpoints/srt_m15_toy.pt` 原始算术权重不覆盖。
- `checkpoints/srt_m15_lm.pt` 原始中文字符权重不覆盖。
- `checkpoints/srt_m15_toy_adapted.pt` 是原有算术自主学习的受控适配权重。

## 联网来源、限制与隐私

- 仅允许向固定的 `https://zh.wikipedia.org/w/api.php` 或 `https://en.wikipedia.org/w/api.php` 发送 **只读**主题检索；没有自定义地址输入，不爬取任意网站，不执行网页脚本，不下载可执行文件。
- 发送至 Wikimedia 的是你在主题或检索框中输入的**关键词**，而不是整个本地聊天记录。不要在主题框中输入个人信息或密钥。
- 每条笔记限制内容长度，本地知识库最多200条，页面显示的内容均按文本而非 HTML 渲染，避免远端 HTML 注入。
- 查询按8秒以上的间隔限速（官方请求频率可能随时变化），单次请求有超时，遇到429/503停止而不连续重试。
- 不使用模型 API，不需要付费 API Key；**获取资料仍需要本机网络可访问维基百科**。如果提示连接失败，可以稍后重试，或者切换到英文百科，并检查当地网络访问情况。
- 资料采集、主题扩展属于简单的规则式自主探索；不是模型拥有独立的互联网规划或可靠事实判断能力。
- Wikipedia 文字通常采用 CC BY-SA 等共享许可。若将摘要或导出的问答公开再发布，请核对对应网页的署名、链接、许可和相同方式共享要求。
- 默认不自动修改模型权重。只有用户主动审核并导出内容，才能用于下一步独立的监督学习实验；本版没有把它接入参数更新器。

## 验证

```bash
python -m unittest discover -s tests -v
```

自动化测试使用模拟 HTTP 响应，不会访问真实维基百科；覆盖网页 URL 安全、来源真实性限制、数据保存、审核/拒绝、手动检索、自动请求次数上限、暂停、重启后默认关闭及原来的神经网络训练。README 和网页中不会将模拟数据宣传为真实网络获取结果。

## 常见问题

**联网后模型会自动变成通用聊天 AI 吗？** 不会。检索文字展示和权重学习是不同的技术；当前语言模型词表和规模仍然有限。

**自动练习与联网学习能同时开启吗？** 可以，两者分别独立运行；CPU 开销主要来自算术训练，联网操作主要依赖网络。

**为什么维基百科没有返回资料？** 网络可能受到限制，API 被限流，关键词过于具体，或者页面不提供摘要。检查页面错误信息后使用其他主题或稍后重试。

**如何完全停止联网？** 点击暂停，然后取消勾选「明确允许联网」。关闭程序也会停止新任务。
