# SRT-M15 自主练习本地版（仅限个位数加法）

这是在 **SRT-M15 自动学习本地版**基础上增加的受控自主练习实验。它在电脑上启动后，可以自动从允许的加法训练题池中取题、调用真正的数学神经网络预测、由确定性验证器核对、保存错误样本，达到门槛后尝试训练候选模型。

**不是通用 AI 自主学习**：不会自主学习中文、写代码、联网搜资料、生成可靠开放问答数据，也不会调用 GPT、DeepSeek 或其他模型 API。

## 1. 电脑上启动

环境：Windows 10/11、macOS 或 Linux，Python 3.10+，PyTorch 2.1+。建议先创建独立虚拟环境。

Windows（命令行）：

```powershell
py -3 -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python start_local.py
```

也可以直接双击 `start_windows.bat`（前提是依赖已安装在系统的 Python 环境中）。

macOS/Linux：

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python start_local.py
```

浏览器访问 **http://127.0.0.1:8765/**。程序仅绑定本机回环地址，不对局域网或互联网公开。**无需 Google Colab**。关闭运行窗口或按 Ctrl+C 可停止服务。

## 2. 如何使用自主练习

1. 页面上方保留「自学习实验」的原有开关、手动训练队列和回滚功能。
2. 在新增加的「**自主练习**」面板设置资源上限，点击 **「▶ 开始自主练习」**。该动作也会启动受控学习开关。
3. 后台自动生成题目、预测和验证；预测错误且属于允许训练范围的样本会进入队列。**无需持续人工提问**。
4. 页面每隔约 3.5 秒显示：**练习题数、预测错误数、待学习样本数、训练尝试次数、接受更新次数、练习轮次**，以及最近一道题的模型预测/验证答案、最近一次训练结果。
5. 点击 **「⏸ 暂停」**可停止继续出题，并关闭自动学习；如果有候选训练正在执行，会申请在最近的训练步骤边界取消。该候选不会被直接写入正式权重。暂停后再次点击「开始自主练习」会开启**新一轮有限预算**；累计统计仍保留。
6. 达到任何指定上限，系统会自动停止继续练习和安排新训练。

默认资源设置及有效范围：

| 设置 | 默认 | 允许范围 | 约束 |
|---|---:|---:|---|
| 练习间隔（秒） | 1 | 0.2～60 | 每轮间至少等待该时间 |
| 每轮题数 | 4 | 1～12 | 一轮最多该题数；模型训练中暂停出题 |
| 最多训练次数 | 2 | 1～8 | **本次自主练习**最多触发的候选训练次数 |
| 最长运行（秒） | 180 | 1～3600 | 超时停止并请求取消尚未完成的候选训练 |
| 最多练习题数 | 100 | 1～500 | 本次运行最多生成的题数 |

底层自动学习控制器另有**累计最多 12 次候选训练尝试**的保护（不同程序重启之间保留），以及候选训练冷却时间；达到累计上限后不再启动新的自主训练。每次候选训练仅执行最多 18 步快速适配更新，不是全模型训练。

## 3. 数据与参数保护

训练前读取**原始数学模型权重文件** `checkpoints/srt_m15_toy.pt` 内记录的题目划分。本实验原始数据恰好包含 100 个不同的两个 0～9 整数加法输入：

- **68 道可用训练题**：自主出题只从这些输入抽样；错误才进入训练队列。
- **12 道原训练集内部保留题**：只用于候选更新的独立检验，不用于自主出题和梯度训练。
- **20 道原始测试题**：不用于出题、梯度训练，也不用于候选更新决策。仍保留作最终评估。

> 上述 68/12/20 为此包内原始权重的实际划分。更换权重后，程序会读取新的划分；如果无法可靠区分训练集和测试集，将拒绝启动自主练习。

候选训练的接受条件同时满足：

1. 来自训练题池的**实际错误样本**，由独立的 `a+b` 确定性验证器提供标签。
2. 在错误样本上，候选模型的**硬路由推理准确率严格优于**更新前。
3. 在**独立的 12 道保留检验题**上，候选模型硬路由准确率**不下降**。候选模型内部同时执行额外的平滑路由检验。
4. 基础检查通过：权重有限、无被保护参数/缓存变化；仅允许分支 `fast_down` / `fast_up` 快速参数改变。

全部通过时才原子保存权重并替换当前数学模型。失败则丢弃候选，保留当前参数。暂停期间已请求取消的候选不会作为有效更新写入。**注意：检验集不是最终泛化测试集；只在该小规模算术任务内观察到的改善，不能代表通用学习能力。**

## 4. 文件与重启恢复

- `checkpoints/srt_m15_toy.pt`：**从不修改**，原始数学权重。
- `checkpoints/srt_m15_lm.pt`：原中文字符模型，**自主练习不会修改**。
- `checkpoints/srt_m15_toy_adapted.pt`：验证通过后保存的最新数学权重，重启优先加载。
- `checkpoints/srt_m15_toy_previous.pt`：最新适配版本之前的版本（若存在）；点击「撤销上次更新」回退。没有更早适配版本时回到原始权重。
- `checkpoints/autolearn_state.json`：经过验证的错误队列、训练次数、最近候选结果。
- `checkpoints/practice_state.json`：累计题数、错误数、轮次、最近题目与停止原因。**不记录自由聊天文本**。

**重启不会自动恢复自主练习运行**：需要重新点击「开始自主练习」。模型权重和已保存的练习统计会自动加载。暂停之后如果没有正在训练的候选，所有工作立即停止；中断训练仍可能需要完成当前的单个计算步骤。

## 5. 运行测试

```bash
python -m unittest discover -s tests -v
```

本版本包含已有网络/聊天测试和新增自主练习/受控更新测试，覆盖：题目范围、错误入队、训练触发、候选接受和拒绝、冻结基础参数保护、暂停/取消、次数和时长限制、状态持久化、权重加载和回滚。项目还能通过本地 HTTP 集成测试启动网页并调用启动/暂停接口。

## 6. 常见问题

**问：自主练习会让模型无限次训练吗？** 不会。每轮练习设置了时间、题数、训练次数上限，控制器还保留累计训练上限。重新启动练习会获得新的**本次运行**预算，但不会重置累计训练上限。

**问：点击暂停会不会删除训练结果？** 不会。已经检验通过并保存的模型版本仍保留；正在计算的候选更新则会尝试取消。需要撤回已经接受的更新，请点击「撤销上次更新」。

**问：能对任意加法训练吗？** 不能。只允许两个 0～9 整数，超过范围需要重新准备数据集并进行独立实验设计。

**问：网络需要一直在线吗？** 电脑本地运行不需要互联网，首次安装 PyTorch 包可能需要联网。
