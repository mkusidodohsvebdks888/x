# SRT-M15：中英双语受控学习版

## 这次增加了什么？

在原有中文问答受控学习的基础上，**同一个 SRT-M15 UTF-8 字节词表语言模型**可以使用简短的中文和英语问答进行候选训练。当前不使用 ChatGPT、DeepSeek 或其他外部模型 API。

- 中英问答各自标记语言 `zh`、`en`。中文采用 `问：...\n答：`；英文采用 `Q: ...\nA: `。
- 自带 **24 组中英对应问答，48 条草稿**。示例全部处于 `draft` 状态，不会自动成为模型训练标签。请逐条检查、批准。
- 自定义中英翻译对可以输入相同的“对应翻译分组”，防止其中一种语言进入训练集、译文进入验证集造成泄漏。引用同一网页来源的问答也保持在同一个分区。
- 默认训练模式“中文 + English”：中英文交替采样；中英文训练集都需要至少3条已批准样本，独立检验集都需要至少2条。
- 更新条件：整体训练目标损失下降至少0.005、**中文和英文各自训练损失不增加、各自验证损失不增加**，权重有限并通过加载检查，才接受候选。
- 也可选择只训中文、只训英文，或“旧版自动”模式。训练步数及最长时长均有上限。
- 支持中英文聊天语言自动判断，或在输入框下方强制指定“中文”“English”。对数学简单加法仍使用原有数学网络。
- 既有 `checkpoints/srt_m15_lm.pt`、`checkpoints/srt_m15_toy.pt` 未改动；新模型只写入 `checkpoints/srt_m15_byte_qa.pt`，可以回滚。

> 这仍然是十万参数量级的**实验模型**。能够编码、训练两种语言不等于具备可靠的中英文理解、翻译或持续自主学习能力。24 对短问答主要用于验证训练管线。真正提高能力仍需要远大于此的可靠语料与更大模型，并用完全未见过的中英文测试集评估。

## Windows 本地启动

1. 解压全部工程，进入 `SRT_M15_Starter` 文件夹。
2. 安装 Python 3.10+，执行 `python -m pip install -r requirements.txt`。
3. Windows 双击 `start_windows.bat`，或运行 `python start_local.py`。
4. 打开 http://127.0.0.1:8765/ 。不需要 Colab。

## 第一次双语训练

1. 找到**「中文 + English · 双语持续学习」**区域。
2. 点击 **「导入24组中英双语示例（48条）」**；页面会显示每条问题/答案、语种、分组和来源。
3. **逐条检查并手工批准**。所有演示条目都能在可滚动列表中找到；若某条不正确，请点击“修改问答”改正后再批准。
4. 等统计显示两种语言分别具备训练和独立检验样本，保持 **「中文 + English（均衡学习）」**。选择训练步数（可从60步开始），然后点击「训练候选语言模型」。
5. 等候候选训练结束，查看 **ZH 与 EN 各自训练/检验损失变化**。只有两种语言都通过保护条件才会替换新权重。
6. 在底部聊天输入框选择“English”测试 `What is a model?`，或选择“中文”测试 `什么是模型`。未学到这些输入时，模型可能生成无意义的续写；这不是程序坏了。输入 `1+9=多少` 继续走数学模块。

## 如何继续添加英语或中文数据？

- 手工填写短问答，选择语种，保存为草稿，再审核批准。**不能将机器自行生成的未验证答案直接视为真值。**
- 若中英两条问题实际上是翻译对，在“对应翻译分组”填写同一英文/数字代号，例如 `weather_001`。相同分组始终进入同一个训练/验证池。
- 上方联网知识区可先后选择英文、中文维基百科并收集资料；核实来源后使用“从已审核资料生成草稿”。生成草稿仍需修改和人工批准，**联网不会自动修改权重**。
- 最多保留160条短问答；本版训练步数最多100、单次最长240秒，避免本地实验无限运行。请备份 `checkpoints/` 与 `language_learning/` 文件夹。

## 旧版兼容与质量保护

- 打开旧版 `language_learning/reviewed_qa.sqlite3` 时会自动增加语言、翻译分组字段，老问题默认中文，审核状态保持原样。升级前建议备份数据库。
- 保留旧版无翻译分组的分区哈希规则，避免升级导致已训练样本重新划分。
- 中英文配对分组，或同一联网来源的内容，整体落在同一分区。
- 候选失败、超时、暂停、审核撤回都不会覆盖旧权重；最新有效更新支持手动回滚（最多一层备份）。
- 训练示例的独立检验仅检查损失，没有提供真正固定的、长期未触碰的英语或中文泛化测试集，因此不能依据一次损失下降来宣称“学会了语言”。
