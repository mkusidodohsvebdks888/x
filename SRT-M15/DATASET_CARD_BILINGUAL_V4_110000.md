# SRT-M15｜新增 100,000 条，累计 110,000 条中英双语实验样本

**状态（2026-10-23）**：提交了离线可复现的数据生成程序 `generate_bilingual_110k.py`，在 GitHub Actions 里先生成数据、进行唯一性/配对/分组校验，再执行限时的多阶段真实梯度训练。生成后输出的 `JSONL` 和 `manifest` 由 Actions 以 artifact 形式保存，**不是从外部网站抓取的真实人类语料**。

## 一、规模

上一版：10,000 条（中文 5,000、英文 5,000）；新增加 **100,000 条**（中文 50,000、英文 50,000），合计 **110,000 条**（中文 55,000、英文 55,000）。每两条以 `topic_id` 为一组，同一话题的中英文都记录为一对，总计 **55,000 个话题组**。

新增内容的类别如下（**注意这是基于模板/算法的合成题，不代表同等数量独立的语言知识**）：

| 类别 | 新话题组 | 新增中英条目 |
|---|---:|---:|
| 加法 | 7,000 | 14,000 |
| 减法 | 6,000 | 12,000 |
| 乘法 | 5,000 | 10,000 |
| 除法 | 4,000 | 8,000 |
| 百分比 | 3,000 | 6,000 |
| 数值比较 | 3,000 | 6,000 |
| 数列 | 3,000 | 6,000 |
| 数字排序 | 3,000 | 6,000 |
| 数学应用题 | 6,000 | 12,000 |
| 时间换算 | 4,000 | 8,000 |
| 日常词汇翻译 | 3,000 | 6,000 |
| 虚构记录信息提取 | 3,000 | 6,000 |
| **合计新增** | **50,000** | **100,000** |

**来源与安全：** 沿用前 10,000 条原始训练示例，新数据全部标注 `synthetic:true`、`verified:false`、`review_status:"unreviewed"` 和生成器版本。没有来源证据时不能批量标注为人工核验。此数据集偏重可程序验证的数学与结构化任务，语言多样性较差，不能代替授权的自然中文、英文语料，也不应被宣传为通用双语模型能力。

## 二、生成方法

```bash
cd SRT-M15
python generate_bilingual_110k.py \
  --output examples/bilingual_synthetic_v4_110000.jsonl \
  --manifest examples/bilingual_synthetic_v4_manifest.json
```

生成器将前一版 10k 数据和新增 100k 数据合并为新的 JSONL，同时检查：总条数、语言平衡、`topic_id` 唯一、中英主题成对、问题去重、家族级训练/验证隔离以及文件 SHA-256。结果可在无网络环境下复现。若校验失败，工作流会报错停止，不得将失败当成已训练成功。

## 三、训练/验证隔离

每个生成模板有固定的 `family_id`，相同家族被整体分到训练或验证侧，以减少仅替换数字/词汇而使模板泄漏的问题。所有中英文对应话题也保持在相同集合。

**这仍非独立自然语言测试**：不同家族之间可能共享相似算术与词汇规律，也可能覆盖范围有限。必须另建独立来源、多轮且经审核的中文/英文测试集。

## 四、GitHub 分批训练

`SRT-M15 staged bilingual training` 工作流默认参数：

- `training_dataset=synthetic_110000`
- `stages=10`，即十个分阶段检查点
- `steps_per_stage=320`，即每批 320 次优化更新
- `batch_size=32`，中英样本各占一半
- `context=256` 字符
- `sampling=cycle`，遍历窗口后才重新采样
- `max_eval_pairs=512`，即从整个留出集稳定选取最多 512 个中英话题组参与每阶段快速验证；**其他留出样本仍完全不参与训练**。

这次计划最多执行 **10 × 320 = 3,200** 个优化步；共输入最多 **102,400 个训练窗口**（不等于 102,400 条完全不同的 QA，每条 QA 可能拆成多个窗口，也会出现不同长度）。训练器在指标中报告实际的唯一训练窗口覆盖数。

工作流保留旧 `synthetic_10000`、`synthetic_1000`、`synthetic_260`、`toy_40` 选项。首次训练 `resume_run_id` 留空；同配置跨 GitHub Actions 运行恢复时填写前一次成功运行 ID，并确保生成器、训练数据哈希、模型参数、批量大小、每阶段步数、词表和采样模式都没有变化。**旧 10k 检查点因数据及词表不同，不能直接通过 `--resume` 用在新 110k 数据上。**

运行产物（若成功）：`latest.pt`、`best.pt`（若达到本实验的提升门槛）、`history.json`、生成后的 `bilingual_synthetic_v4_110000.jsonl` 和 `manifest.json`。GitHub Actions artifacts 设置保留 14 天，请及时下载保存。

## 五、验收尺度与后续研究

本版不能仅用“110,000 条”或“loss 降低”来表示达到普遍中英文对话水平。需要关注独立中文和英文问答质量、语法、对长文本的理解、多轮记忆、常见事实问答，以及新的人工审核的评测集。**当前原生 SRT-M15 仍是很小的教学实验网络**，不具备通用语言模型的容量和真实语料规模。
