# 独立模型版本：什么已经保存，什么还没有

## 用户目标

上游作者以后发布新版或修改代码，我保存的版本不随之更新。

## 当前已实现：固定原始版本

- 25 个模型在 versions.lock.json 中有 2026-10-24 查询的固定 40 位 commit SHA。
- 11 家模型的 download.py 默认按 SHA 下载，不追踪上游 main。
- 这些文件属于你自己的 GitHub 仓库；只有你主动更改才更新这些清单。

## 当前未实现：实际文件的独立副本

目前没有将完整模型权重、分词器和源代码复制到你的 GitHub。固定提交编号不等于拥有这些文件。若上游删除仓库或取消访问，可能无法重新取得原版。

要真正独立于上游，必须下载所有必需文件，保存到自己拥有且允许存放的独立存储中，并做备份。可分别 Fork 官方的 GitHub 源代码仓库，但 Fork 不会自动复制 Hugging Face 的大型模型权重。GitHub 普通 Git 单文件上限为 100 MiB，不适合存多 GB 模型文件。

GPT-4o 不提供可公开下载的完整权重；gpt-oss 是不同模型。

## 操作方式（不会自动运行）

进入 大模型/DeepSeek 后执行：

    python download.py --list
    python download.py --model R1-Distill-1.5B --dry-run

除非你主动执行真正的下载并另行保存权重，否则 GitHub 里仍只有固定版本清单。
